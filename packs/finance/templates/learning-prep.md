## Core Formulas
| Formula | When to use |
|---------|-------------|
| WACC = wE×ke + wD×kd(1-t) | Discount rate for unlevered FCF |
| TV = FCF×(1+g)/(WACC−g) | DCF terminal value (Gordon Growth) |
| MOIC = Exit Equity / Entry Equity | LBO return (quick check) |

## Common Tricks / Traps
- DCF: terminal value often 60–80% of total EV — sanity-check it
- LBO: always build a S&U table first, derive equity check last
- Ratios: compare to peer median, not absolute benchmarks

## Likely Question Types
1. Quick valuation: given EBITDA and multiple, what's EV?
2. Capital structure: optimal D/E given tax shield vs distress cost
3. Case analysis: identify key financial risk in case X
