# Strategy Learning Prep — [Topic]

## Core Frameworks (when to use each)
| Framework | Best for | Pitfall |
|-----------|----------|---------|
| Five Forces | Industry attractiveness | Don't apply to a single firm |
| VRIO | Sustainable advantage | Needs all 4 to sustain |
| BCG Matrix | Portfolio decisions | Ignores synergies |
| Value Chain | Cost/differentiation source | Boundaries matter |
| Blue Ocean | New market creation | Hard to defend |

## Key Concepts
- **Generic strategies:** Cost leadership vs differentiation vs focus — can't be stuck in the middle
- **Industry vs firm effects:** ~50/50 empirically — both matter
- **First-mover advantage:** Only durable if backed by switching costs, network effects, or learning curves

## Likely Exam Question Types
1. Analyse industry X using Five Forces → what is the strategic implication for firm Y?
2. Evaluate the strategic options facing [protagonist] — recommend with justification
3. Is [company]'s competitive advantage sustainable? Apply VRIO.
