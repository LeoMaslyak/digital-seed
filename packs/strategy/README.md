# Strategy Pack

**your context Business Policy & Competitive Strategy support**

## What's included

**Patterns:**
- `five-forces` — Porter's Five Forces with industry attractiveness summary
- `bcg-matrix` — Portfolio analysis with SBU mapping
- `competitive-dynamics` — Competitor profiling, VRIO, competitive interaction

**Agent override:** `study.yaml` — Strategy-tuned study specialist

**Templates:** `project-analysis.md`, `learning-prep.md`

## Install

```bash
bun run marketplace install pack:strategy
```

## Usage

```
Analyse the competitive dynamics of the global coffee industry
and advise Nespresso on their strategic position.
```
