# Operations Learning Prep

## Core Formulas
| Formula | What it gives you |
|---------|------------------|
| I = R × T | Little's Law — always check consistency |
| Utilisation = D / C | % of capacity used at each step |
| Safety stock = z × σ × √LT | Buffer against demand/supply uncertainty |
| EOQ = √(2DS/H) | Optimal order quantity |
| OEE = Availability × Performance × Quality | Manufacturing efficiency |

## Common Exam Traps
- Little's Law: make sure units are consistent (hrs vs days vs weeks)
- Bottleneck: adding capacity elsewhere does NOT improve throughput
- Safety stock: only protects against variability — not mean demand

## Process Analysis Checklist
1. Map the process (activities, times, resources)
2. Find capacity per step = 1/cycle time × # resources
3. Find bottleneck = min capacity step
4. Calculate utilisation = demand / capacity
5. Apply Little's Law to verify I, R, T consistency
6. Recommend: expand bottleneck, reduce variability, or reduce batch size
