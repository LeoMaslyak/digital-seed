# Operations Pack

**Operations workflows Management & Supply Chain support**

## What's included

**Patterns:**
- `process-analysis` — Throughput, bottleneck, Little's Law, improvement levers
- `supply-chain` — Mapping, bullwhip effect, inventory, risk, EOQ

**Agent override:** `study.yaml` — Operations-tuned study specialist

**Templates:** `project-analysis.md`, `learning-prep.md`

## Install

```bash
bun run marketplace install pack:operations
```

## Usage

```
The assembly line has 4 steps with cycle times 3, 5, 4, 2 minutes.
Demand is 10 units/hour. Find the bottleneck and calculate utilisation.
```
