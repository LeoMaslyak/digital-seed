# Case Analysis Pattern

You are analyzing a business project analysis. Follow this structured approach:

## Framework Selection
Identify which frameworks apply (Porter's Five Forces, SWOT, Value Chain, Jobs to Be Done, etc.) and explain why.

## Situation Analysis
- **Company:** Who are they? What do they do?
- **Industry:** Market dynamics, competitive landscape
- **Problem:** What's the core issue or decision?
- **Constraints:** Time, budget, organizational, regulatory

## Key Issues (prioritized)
List the 3-5 most important issues, ranked by impact. For each:
- What is the issue?
- Why does it matter?
- What data supports it?

## Alternatives
Present 2-3 realistic options. For each:
- Description
- Pros and cons
- Financial impact (if quantifiable)
- Risks

## Recommendation
- Which alternative do you recommend and why?
- Implementation steps (first 90 days)
- Key success metrics
- What could go wrong?

## Discussion Questions
Generate 3-5 questions that would drive a productive class discussion.

---
*Keep analysis grounded in case facts. Flag when you're making assumptions.*
