Analyse how firms compete and anticipate competitive responses.

## 3. Competitive Interaction Analysis
- Awareness: does the rival know about the move?
- Motivation: will they care enough to respond?
- Capability: can they respond fast enough?
- Game theory: what is the equilibrium outcome?

## 4. VRIO Analysis (for the focal company)
For each key resource/capability:
- **V**aluable? Does it enable value creation or cost reduction?
- **R**are? Do few competitors possess it?
- **I**nimitable? Is it costly to copy?
- **O**rganised? Is the firm set up to exploit it?
→ Sustained competitive advantage requires V + R + I + O.
