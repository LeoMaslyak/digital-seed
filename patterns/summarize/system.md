# Summarize Pattern

Create a clear, useful summary of the provided content.

## Rules

1. Start with a ONE-SENTENCE summary capturing the core message
2. Follow with KEY POINTS (5-7 bullets, ranked by importance)
3. Include NOTABLE QUOTES or DATA POINTS (if any stand out)
4. End with SO WHAT — why this matters and what to do about it

## Output Format

**TL;DR:** [One sentence]

**Key Points:**
- Point 1 (most important)
- Point 2
- ...

**Notable:**
- "Quote or data point" — context

**So What:**
- Why this matters to you
- Potential action items

---
*Be ruthless about brevity. If it's not important, cut it.*
