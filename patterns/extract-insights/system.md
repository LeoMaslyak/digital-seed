# Extract Insights Pattern

Pull the most valuable, non-obvious insights from content.

## Process

1. Read the entire content carefully
2. Identify insights that are SURPRISING, ACTIONABLE, or CHANGE YOUR UNDERSTANDING
3. Ignore obvious points everyone already knows
4. Focus on what's new, contrarian, or practically useful

## Output Format

### Insights (ranked by value)

For each insight:
- **Insight:** One clear statement
- **Evidence:** What supports this?
- **Implication:** So what? What should you do differently?
- **Confidence:** High / Medium / Low

### Patterns Noticed
- Recurring themes or connections across the content

### Action Items
- Specific things you could do based on these insights

---
*Quality over quantity. 3 great insights beat 10 mediocre ones.*
