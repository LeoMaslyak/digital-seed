# Agent Chooser

Digital Seed does not recommend one agent for everyone.

Different tools are good for different styles of work. This guide helps you understand what is what so you can choose for yourself.

## Claude Code

Best for:

- working in a terminal
- editing repos and project folders
- building software or documentation
- asking an AI to inspect files and make changes

Good fit if:

- you are comfortable with command-line workflows
- your work lives in folders and Git repos
- you want strong project-level reasoning

## Cursor / Windsurf

Best for:

- coding inside an editor
- interactive software development
- navigating and editing codebases visually

Good fit if:

- you already live in an IDE
- you want AI help while editing files
- you prefer visual workflows over terminal workflows

## OpenClaw

Best for:

- always-on personal AI infrastructure
- messaging-based assistant access
- background tasks, crons, agents, tools, nodes, and workflows
- building a more autonomous personal operating system

Good fit if:

- you want an assistant that can keep running when you are not in the terminal
- you want Telegram/Discord/Slack-style access
- you want to connect many tools and agents over time

## Hermes Agent

Best for:

- agentic personal assistant workflows
- structured personal AI operations
- integrating a persistent assistant with your own context and tools

Good fit if:

- you want an agent-oriented setup rather than just a coding assistant
- you are comfortable configuring a personal AI worker
- you want Digital Seed context files to feed a broader assistant

## Telegram / Discord / Slack front-ends

Best for:

- talking to your assistant from phone or desktop chat
- quick capture
- notifications
- lightweight command access

Good fit if:

- you want mobile access
- you want your assistant to feel like a normal chat contact
- you already use these apps heavily

## How to choose

Ask yourself:

1. Do I mostly work in code/projects? Start with Claude Code, Cursor, or Windsurf.
2. Do I mostly want a personal assistant/chat interface? Look at OpenClaw or Hermes.
3. Do I need background automation? Look at OpenClaw/Hermes always-on mode.
4. Do I just want to understand personal AI infrastructure? Start with Digital Seed context files and docs first.

You can combine tools. Digital Seed is the shared context layer that helps them understand you.
