# Visual Story

This folder holds the public-facing Digital Seed visual assets. They are designed for use in documentation, slides, and onboarding without requiring JavaScript or a build step.

## Files

- `Digital Seed — Growth Loop.mp4` — premium animated loop (MP4, broad compatibility)
- `Digital Seed — Growth Loop.webm` — same loop in WebM (smaller, modern browsers)
- `Digital Seed — Growth Loop.gif` — animated GIF for surfaces that block video
- `Digital Seed — Growth Still.png` — single hero frame for thumbnails and OG images
- `Digital Seed - Magical Tree.svg` — lightweight SVG version of the tree metaphor

## The metaphor

- seed → core personal context (USER, COMPASS, GOALS)
- roots → local files and memory
- trunk → a stable workflow
- branches → tools and integrations
- lights → useful automations added carefully

## Usage

Pick the format that matches the surface:

- GitHub README, blog posts: GIF or PNG
- websites, decks: MP4 or WebM
- docs that need to scale crisply: SVG
- social cards, thumbnails: PNG still

The visuals are regenerated from `scripts/generate-visual-assets.py` in the repo.
