# Digital Seed v0.4.2-alpha

## Summary

`v0.4.2-alpha` is a major onboarding, agent-choice, and public-usability release. It introduces the phase system, guided agent-based setup, a broader agent ecosystem (Codex CLI, Gemini CLI, Ollama), beginner install guides, an explicit friction-reporting path, and the `what-next` command. It also corrects stale agent login commands found during a hostile audit.

This is a stronger public alpha. It is **not** a 1.0 release candidate: real external-user validation remains the hard gate for any 1.0 tag.

## What's new

**Phase system**
- `docs/phases.md` — four phases users choose from: Local context → Local search → Integrations → Always-on agent. Clear descriptions of what each phase installs, what it skips, and how long it takes.
- `bun run seed plan` — prints a paste-ready prompt for your AI agent. The agent interviews you, recommends phases, and runs setup commands. `--write-plan` creates `user/MY-PLAN.md`.
- `bun run seed what-next` — reads `user/MY-PLAN.md` and prints exactly one next action. Removes the "I finished Phase 1, now what?" gap.
- `setup.sh` phase chooser replaces the flat profile picker.

**Broader agent support**
- `docs/agent-chooser.md` fully rewritten with Claude Code, Codex CLI, Gemini CLI, Ollama, Cursor/Windsurf, OpenClaw/Hermes — quick-pick table, honest caveats, install commands.
- `docs/install-codex-cli.md` — complete beginner install guide for Codex CLI (OpenAI): macOS + WSL2, login, first run, troubleshooting.
- `docs/install-gemini-cli.md` — complete beginner install guide for Gemini CLI (Google): same structure.
- `bun run seed doctor` now detects `claude`, `codex`, `gemini`, `cursor`, `windsurf`, `ollama`.
- README prereqs now lists all four agent options with install commands.

**Feedback and friction reporting**
- `bun run seed feedback` — prints direct GitHub issue-template links. `--write-draft` creates a local draft.
- `.github/ISSUE_TEMPLATE/first_run_friction.yml` — dedicated template for "I got confused" reports.
- `docs/feedback.md` — non-technical path to issues and GitHub-web PR edits.

**Hostile audit fixes**
- `claude login` corrected to `claude auth login` throughout docs, CLI, and setup wizard.
- `gemini auth login` corrected to "run `gemini` and follow the sign-in prompt" (the subcommand does not exist in current Gemini CLI).

**Documentation**
- `docs/public-usability-roadmap.md` — concrete M1–M8 milestone list, updated scorecard (~85%).
- `docs/simulated-public-alpha-readiness-2026-05-12.md` — hostile audit of all 2026-05-12 changes.
- P2 audit backlog resolved: SECURITY privacy-scan pointer, CONTRIBUTING repo shape, README data-room qualifier, old audit cross-link.

## Why this release matters

`v0.4.1-alpha` made the repo honest. `v0.4.2-alpha` makes it approachable for people who are not already Claude Code users.

The three biggest previous gaps were:
1. No clear "what do I install?" answer for non-Claude users → now: agent-chooser quick-pick table + Codex/Gemini install guides.
2. No clear "what do I do next?" after Phase 1 → now: `seed what-next` + `seed plan`.
3. No easy friction-reporting path for non-technical users → now: `seed feedback` + first-run friction template.
