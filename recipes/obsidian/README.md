# Obsidian Recipe

Use this when your notes live in an Obsidian vault.

1. Keep the vault local.
2. Point Digital Seed at the vault folder when indexing.
3. Ask your agent to cite the note path when it answers from notes.

Example:

```bash
bun run seed index ~/Documents/Obsidian
bun run seed search "what do my notes say about my goals?"
```
